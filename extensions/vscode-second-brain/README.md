# Second Brain for VS Code, Cursor & Windsurf

- **Sidebar Vault Explorer**: Browse Notes and Verified Atoms.
- **Remember Selection** (`Ctrl+Alt+M`): Capture selected code or prose directly into Second Brain.
- **Quick Recall** (`Ctrl+Alt+R`): Instant fuzzy search across your vault.
- **Streaming Chat**: Query your vault with `Stream`, `Verified`, or `Instant` modes.
