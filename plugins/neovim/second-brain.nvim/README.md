# second-brain.nvim

Zero-dependency Neovim Lua plugin for Second Brain loopback HTTP & MCP Hub (`~/.config/mcphub/servers.json`).

Commands:
- `:SecondBrainRecall <query>` — Query owner-approved atoms in a floating citation preview window.
- `:SecondBrainRemember <note>` — Stage working notes cleanly via `/v1/remember`.
- `:SecondBrainPlan <goal>` — Generate grounded Executive Plans from verified atoms & playbooks.
