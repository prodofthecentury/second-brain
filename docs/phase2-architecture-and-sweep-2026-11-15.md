# Phase 2 Architecture & Adversarial Security Sweep (2026-11-15)

## 1. Executive Summary

Phase 2 extends the Milestone 1–6 Local Pilot Foundation into a **Host-Independent Universal Brain Plugin & Cognitive Core** while preserving all **5 Non-Negotiable System Invariants**:

1. **Durable Storage Invariance:** Canonical Markdown atoms (`brain/2-atoms/*.md`), immutable source artifacts (`brain/0-raw/*`, `brain/sources/*`), and create-only episode logs (`brain/4-experiences/*.md`) remain the sole durable state. SQLite FTS5 (`lexical.sqlite3`), Chroma (`.chroma/`), and Cognitive Telemetry (`telemetry.sqlite3`) are disposable, zero-churn projections under `brain/.sidecar/`.
2. **Deterministic Compare-and-Swap (CAS):** Canonical atoms are mutated exclusively through `scripts/atom_mutator.py` under OS file locking (`writer.lock`). Untrusted captures and procedural proposals land strictly in `brain/0-raw/inbox/` and require explicit SHA-256 CAS owner promotion (`scripts/inbox_workflow.py`) before Refinery ingestion.
3. **Cryptographic Source Anchoring:** Every approved atom requires an exact byte-offset SHA-256 match against its local source artifact (`scripts/audit_sources.py`).
4. **Out-of-Model Epistemic Grounding:** Every model response—whether drafted by local Ollama (`ollama_local`), custom local servers (`owner_custom_local`), or explicitly opted-in online providers (`openai_online`, `anthropic_online`, `gemini_online`)—is validated outside the model by `scripts/answer_policy.py`. Non-verbatim claims are excised; unsupported queries structurally abstain.
5. **Fail-Closed Security & Hermetic Operation:** Both the Dashboard (`127.0.0.1:8501`) and the Loopback Memory API (`127.0.0.1:8765`) reject non-loopback binds (`0.0.0.0`), cross-origin/cross-site browser requests, and unauthenticated calls. Online AI host calls are disabled by default (`enabled: false`), enforce DNS-pinned HTTPS (`port 443`, public IP verification, zero redirects, `trust_env=False`), filter atoms by `project:<id>` containment, scrub PII, and abort on credential/secret patterns.

## 2. Phase 2 Engineering Tracks

### Track 1: Hardware-Tiered Capability Profiles (`scripts/hardware_profile.py`)
- Deterministically inspects OS/kernel, CPU threads, total/available RAM, native C++ ABI (`vcruntime140.dll` on Windows, `libstdc++.so.6` on Linux, `libc++` on macOS), discrete GPU/VRAM (`cuda`, `rocm`, `metal`, `cpu`), and loopback-verified Ollama daemon models (`http://127.0.0.1` only, `ProxyHandler({})`, zero redirects).
- Classifies each host into one of four explicit capability tiers:
  - `tier_0_lexical_only`: Offline/model-free SQLite FTS5 mode (`< 10 ms` P50).
  - `tier_1_cpu_compact`: Compact CPU (`< 12 GiB` RAM) recommending `llama3.2:3b` + `lexical`.
  - `tier_2_cpu_balanced`: Multi-core CPU (`>= 12 GiB` RAM) recommending `qwen2.5-coder:7b` + `lexical` (with opt-in `rrf`).
  - `tier_3_gpu_accelerated`: Discrete GPU (`>= 8 GiB` VRAM or Apple Silicon unified memory `>= 16 GiB`) recommending `qwen2.5:14b` / `qwen2.5-coder:7b` + `rrf` hybrid search.
- Integrated into `second-brain profile [--json]`, `second-brain doctor`, `setup.ps1`, `setup.sh`, Dashboard System Health, and `GET /v1/profile`.

### Track 2: Quarantined Inbox Promotion Workflow (`scripts/inbox_workflow.py`)
- Provides full lifecycle management for untrusted captures in `brain/0-raw/inbox/` originating from MCP (`add_to_inbox`), the Loopback HTTP API (`POST /v1/inbox`), or Cognitive Core procedural proposals.
- **Risk Scanner:** Flags `forged_accepted_status`, `forged_epistemic_contract`, `forged_established_certainty`, `prompt_override_directive`, `outbound_markdown_beacon`, `embedded_html_or_script`, and `suspected_credential_material`.
- **Sanitized CAS Promotion & Rejection:** `promote_inbox_item()` and `reject_inbox_item()` acquire `writer.lock`, verify `expected_sha256`, require `acknowledge_risks=True` when risk flags exist, strip forged YAML frontmatter (even after leading HTML origin comments) and embedded HTML comments, defang inline/angle-bracketed/reference-style/`<img>` beacons, block `"user_local"` origin laundering, move originals to collision-safe `archive/inbox-promoted/` or `archive/inbox-rejected/`, and append `0600` symlink-checked audit records to `inbox-decisions.jsonl`.
- **Multi-Atom Verbatim Refinery (`scripts/ollama_refinery.py`):** Structured extraction preserves exact verbatim `evidence_quote` substrings and multi-atom separation while leaving all generated candidates strictly `review_status: pending`.

### Track 3: Per-Host Online & Custom AI Adapters (`scripts/host_adapters.py`)
- Supports `ollama_local` (`ollama`), `owner_custom_local` (`openai_compatible` on `http://127.0.0.1`), `openai_online` (`openai_compatible`), `anthropic_online` (`anthropic` tool-use schema), and `gemini_online` (`gemini` structured `responseSchema`).
- **Consent & Scope Gate (`host-sharing-policy.json`):** Stored in the OS user security state directory (`%LOCALAPPDATA%\SecondBrain\security\host-sharing-policy.json` with owner-only NTFS DACL / POSIX `0600`). Online hosts default to `enabled: false` and `allowed_projects: []`. Multi-project atoms require **every** `project:<id>` tag on the atom to be permitted by the target host (`all(...)` containment), and preference atoms require `allow_preference_atoms: true`.
- **Outbound Secret & PII Gate:** Scans prompts before network transmission. High-risk secrets (OpenAI/Anthropic/Google/AWS/GitHub/HuggingFace/Slack/Stripe keys, JWTs, PEM private keys, basic-auth URLs, Bearer headers) raise `OutboundSecretBlockedError` before any socket opens. For `redact_pii: true` hosts, PII in claims/evidence/metadata/queries (emails, RFC 1918 / CGNAT / link-local / IPv6 ULA addresses, Windows/POSIX home paths) is replaced on the wire with deterministic per-call `[REDACTED_PII:<kind>:<N>]` placeholders (`_redact_outbound_with_map`) and rehydrated strictly locally from the in-memory per-call map (`_rehydrate_draft_claims`) prior to `validate_standard_answer()`, rejecting forged or unknown placeholder tokens.
- **DNS-Pinned HTTPS Transport:** Online endpoints require `https://` on standard port `443`, resolve DNS once, reject non-public IPs, bind connections directly to the validated IP via `PinnedHTTPTransport` while preserving TLS SNI, and audit every outbound call to `brain/.sidecar/outbound-host-audit.jsonl`.

### Track 4: Cognitive Core Layer (`scripts/cognitive_core.py`)
- **Zero-Churn Disposable Telemetry (`brain/.sidecar/telemetry.sqlite3`):** Tracks `retrieval_hits`, `candidate_hits` (via `peek_lexical_candidate_atom_ids()`), `grounded_citations`, `positive_feedback`, `corrections`, and recall/answer latency/abstention events in SQLite WAL mode without ever touching `brain/2-atoms/*.md` revision hashes.
- **Memory Fitness & Procedural Skill Maturity:** Computes utility scores, identifies high-utility vs. cold verified atoms, surfaces pending review bottlenecks (stripping unapproved `atom_id` values on external `/v1/cognitive/fitness` responses while retaining full attribution in owner-local CLI/Dashboard views), and tracks procedural atoms across `procedural_draft` -> `verified_procedure` -> `skill_candidate` (`>= 3` grounded citations and `0` corrections).
- **Create-Only Experience Records (`brain/4-experiences/`):** Persists structured task episodes (`goal`, `actions`, `result_summary`, `lessons`, `referenced_atoms`) under `writer.lock` with sanitized single-line headers; optional `propose_procedure=True` writes quarantined procedural drafts strictly to `brain/0-raw/inbox/`.

### Track 5: Host-Independent Loopback Memory API & SDK (`scripts/memory_api.py`)
- **HTTP JSON Service (`127.0.0.1:8765`):** Multi-threaded `ThreadingHTTPServer` enforcing strict `127.0.0.1` bind validation, 10s socket read timeouts, `Content-Length <= 65536` (rejecting `Transfer-Encoding`), strict `Host` allowlist (DNS-rebinding defense), `Origin` and `Sec-Fetch-Site` (`cross-site` -> `403`) CSRF defense, constant-time 256-bit Bearer token auth, and brute-force rate limiting (`429` after 5 bad guesses while never locking out valid Bearer holders or unauthenticated `<img>` noise).
- **Endpoints:** `GET /v1/health`, `GET /v1/profile`, `GET /v1/inbox/queue`, `GET /v1/cognitive/fitness`, `POST /v1/recall` (approved atoms only), `POST /v1/answer` (grounded via `host_adapters.py` + `answer_policy.py`), `POST /v1/inbox` (quarantined capture), and `POST /v1/cognitive/experiences` (bounded episode log).
- **Typed Python SDK & Host Descriptors:** `MemoryApiClient` (`httpx`, `trust_env=False`, `follow_redirects=False`) and `second-brain adapter-config` templates for VS Code / Cursor / Windsurf, Claude Desktop / Claude Code, Codex CLI, JetBrains IDEs, and custom local agents.

## 3. Independent Adversarial Security Audit Reconciliation

An isolated read-only `security-auditor` review (`b8248c56-e4ba-423f-85d9-1fda32190901`) audited all Phase 2 modules and identified 12 findings (`1 CRITICAL`, `3 HIGH`, `4 MEDIUM`, `3 LOW`, `1 INFO`). Every finding has been remediated in source and locked down by regression tests in `scripts/phase2_safety_tests.py`:
