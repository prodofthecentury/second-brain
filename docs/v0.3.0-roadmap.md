# Second Brain v0.3.0 — Distribution & Feature Roadmap

`v0.2.0` established the complete local-first, evidence-grounded memory core, 17-tool MCP server, multi-host DLP streaming chat, Three-Store Merkle ledger, Time-Travel snapshots, and cross-platform Desktop/VS Code/Dashboard surfaces.

`v0.3.0` focuses on **zero-trust cross-device sync**, **zero-friction browser capture**, **multi-vault workspace isolation**, and **trusted public distribution** without weakening any of the 5 Non-Negotiable System Invariants.

---

## Milestone 1 — End-to-End Encrypted Multi-Device Vault Sync — COMPLETE (`0cccfe7`)

**Goal:** Synchronize durable vault files (`notes/`, `2-atoms/`, `4-experiences/`, `5-playbooks/`, `0-raw/archive/` + source files) across the owner's devices over untrusted object storage (S3 / R2 / WebDAV / Git / folder sync) with zero plaintext exposure.

### Architecture & Invariants
- **Cipher & Key Hierarchy:** `scrypt` (`N=2^15, r=8, p=1`) passphrase KDF or 256-bit recovery keyfile -> per-vault `HKDF-SHA256` subkeys -> `AES-256-GCM` authenticated encryption with random 96-bit nonces and strict AAD binding (`sb-sync-v1|<vault_id>|<kind>|<object_id>`), `HMAC-SHA256` blind blob IDs (so storage providers cannot fingerprint duplicate files), and `Ed25519` device-signed + master-key `HMAC-SHA256` (`head_mac`) authenticated sync heads with monotonic anti-rollback epoch enforcement.
- **CAS & Conflict Semantics:** Sync runs exclusively under `writer.lock`. Fast-forward updates to `2-atoms/` and `5-playbooks/` preserve prior revisions in `.history/`; divergent concurrent edits never silently overwrite: local wins its path while the remote revision is quarantined under `0-raw/sync-conflicts/` and surfaced in the Sync status/conflict view. Remote deletions propagate cleanly when unmodified locally (recording `modify_delete` conflicts when locally edited).
- **Ledger Continuity:** Syncing merges append-only JSONL lineage logs (`decision-record.jsonl`, `manifest.jsonl`, `atom-corrections.jsonl`, `mcp-audit.jsonl`) via deterministic UTC-normalized set-union; `.sidecar/` and `.chroma/` are never uploaded and are rebuilt locally on pull.

### Deliverables
- `scripts/vault_sync.py` + `second-brain sync init|join|push|pull|status|verify`
- `/v1/sync/status`, `/v1/sync/init`, `/v1/sync/join`, `/v1/sync/pull`, `/v1/sync/push`, `/v1/sync/verify` (owner-token gated)
- Desktop, VS Code & Dashboard Sync controls + conflict visibility
- Adversarial tests: ciphertext tamper/AAD swap detection, wrong-key & unauthenticated `head.json` fail-closed rejection, concurrent edit & modify-delete conflict preservation, remote deletion propagation, zero `.sidecar/` leakage.

## Milestone 2 — Local-First Browser Web Clipper (Chrome / Edge / Firefox) — COMPLETE

**Goal:** Capture highlighted web passages or full cleaned articles directly into `brain/notes/` or quarantined `0-raw/inbox/` over `127.0.0.1` without any third-party cloud service.

### Architecture & Invariants
- **Loopback-Only Transport:** Manifest V3 extension talks strictly to `http://127.0.0.1:<port>/v1/clipper/*` using owner-paired extension origins (`chrome-extension://<32-char-id>` / `moz-extension://<uuid>`) and write-only scoped `clipper_*` bearer tokens (stored exclusively as SHA-256 hashes in `clipper-pairings.json`).
- **Verifiable Web Provenance:** Clean captures store `source_url`, `captured_at`, exact selected quote, and full page text SHA-256 snapshot in `0-raw/note-snapshots/clip-*.md` so promoting a clipped quote via `verify_note_excerpt` preserves cryptographic byte-offset anchoring.
- **DLP Pre-Screen:** Server-side secret & prompt-injection scanner withholds `0-raw/note-snapshots/` persistence, redacts detected credentials, and quarantines risky clips automatically to `0-raw/inbox/`.

### Deliverables
- `extensions/browser-clipper/` (Manifest V3 Chrome/Edge/Firefox package)
- One-click pairing token flow in Desktop & Dashboard (`second-brain clipper pair`)
- Automated extension unit + loopback integration tests.

## Milestone 3 — Multi-Vault Workspaces & Access Profiles — COMPLETE

**Goal:** Let owners maintain isolated vaults (e.g., `Personal`, `Work`, `Client-A`) with separate tokens, policies, and encryption keys while supporting fast workspace switching and opt-in cross-vault read-only search.

### Architecture & Invariants
- **Named Vault Registry:** `SecondBrain/security/vaults.json` (`0600`/NTFS DACL) tracks `{vault_id, label, path, default_host_policy}` while keeping `vault-path.txt` as the live active pointer for zero-breakage CLI/MCP/Dashboard/VS Code parity.
- **Strict Isolation Default:** Each vault retains its own `writer.lock`, `decision-record.jsonl`, `vault-ledger.jsonl`, and optional per-vault bearer token; cross-vault recall requires explicit owner opt-in per query and never crosses project/client boundaries implicitly.

### Deliverables
- `second-brain vault list|create|switch|remove`
- Desktop & VS Code quick-switcher dropdown with live API/MCP synchronization
- Isolation penetration tests ensuring vault A credentials/queries never read vault B.

## Milestone 4 — Production Distribution & Trusted Signing — COMPLETE (`v1.0.0`)

**Goal:** Make installation effortless and warning-free on Windows, macOS, and Linux.

### Deliverables
- **CI/Release Pipeline (`.github/workflows/release.yml` — implemented in `v0.2.0`, expanded through `v1.0.0`):** Tag-triggered multi-OS release workflow building Windows `.exe`/`.msi`, macOS universal `.dmg`/`.zip`, Linux `.AppImage`/`.deb`, Python `.whl`, VS Code `.vsix`, MV3 Browser Clipper `.zip`, Mobile Inbox Drop PWA `.zip`, WinGet & Homebrew Cask manifests, and unified `SHA256SUMS.txt` gated by the 23-suite verification pipeline.
- **Trusted Code Signing Secrets (Supported in `.github/workflows/release.yml`):**
  - Windows: CA-issued EV/OV `.pfx` (`WINDOWS_PFX_BASE64`, `WINDOWS_PFX_PASSWORD`) with inner+outer Authenticode signing (`scripts/package_desktop.ps1`, `scripts/sign_release.ps1`).
  - macOS: Apple Developer ID Application cert + App-Specific notarization (`MAC_CSC_LINK`, `MAC_CSC_KEY_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`).
- **Package Managers & Registries (`scripts/build_distribution_manifests.py`):**
  - PyPI Trusted Publishing (`pip install second-brain` / `uv tool install second-brain`)
  - VS Code Marketplace + Open VSX (`VSCE_PAT`, `OVSX_PAT`)
  - Automated WinGet (`SecondBrain.SecondBrain.yaml`) and Homebrew Cask (`second-brain.rb`) manifests bound directly to `SHA256SUMS.txt` release digests.
