# Second Brain v0.3.0 — Distribution & Feature Roadmap

`v0.2.0` established the complete local-first, evidence-grounded memory core, 17-tool MCP server, multi-host DLP streaming chat, Three-Store Merkle ledger, Time-Travel snapshots, and cross-platform Desktop/VS Code/Dashboard surfaces.

`v0.3.0` focuses on **zero-trust cross-device sync**, **zero-friction browser capture**, **multi-vault workspace isolation**, and **trusted public distribution** without weakening any of the 5 Non-Negotiable System Invariants.

---

## Milestone 1 — End-to-End Encrypted Multi-Device Vault Sync — COMPLETE (`0cccfe7`)

**Goal:** Synchronize durable vault files (`notes/`, `2-atoms/`, `4-experiences/`, `5-playbooks/`, `0-raw/archive/` + source files) across the owner's devices over untrusted object storage (S3 / R2 / WebDAV / Git / folder sync) with zero plaintext exposure.

### Architecture & Invariants
- **Cipher & Key Hierarchy:** Argon2id passphrase + OS keychain master key -> per-vault HKDF subkeys -> XChaCha20-Poly1305 authenticated encryption per content-addressed blob (`sha256(plaintext)` -> encrypted blob key `hmac(key, plaintext_sha256)` so storage providers cannot even fingerprint duplicate files).
- **CAS & Conflict Semantics:** Sync runs exclusively under `writer.lock`. Divergent concurrent edits to the same Markdown file never silently overwrite: local wins its path while the remote revision is written as `<name>.conflict-<device>-<sha8>.md` and surfaced in the Desktop/Dashboard Review Queue.
- **Ledger Continuity:** Syncing merges `decision-record.jsonl`, `atom-corrections.jsonl`, and `vault-ledger.jsonl` via deterministic Merkle-checkpoint lineage checks; `.sidecar/` and `.chroma/` are never uploaded and are incrementally rebuilt locally on pull.

### Deliverables
- `scripts/vault_sync.py` + `second-brain sync init|push|pull|status`
- `/v1/sync/status`, `/v1/sync/pull`, `/v1/sync/push` (owner-token gated)
- Desktop & Dashboard Sync panel + encrypted conflict resolution modal
- Adversarial tests: ciphertext tamper detection, wrong-key fail-closed rejection, concurrent edit conflict preservation, zero `.sidecar/` leakage.

## Milestone 2 — Local-First Browser Web Clipper (Chrome / Edge / Firefox) — COMPLETE

**Goal:** Capture highlighted web passages, PDFs, or full cleaned articles directly into `brain/notes/` or quarantined `0-raw/inbox/` over `127.0.0.1` without any third-party cloud service.

### Architecture & Invariants
- **Loopback-Only Transport:** Manifest V3 extension talks strictly to `http://127.0.0.1:<port>` (auto-configured via one-click pairing from Desktop Settings -> `POST /v1/notes` or `POST /v1/inbox` with scoped bearer token).
- **Verifiable Web Provenance:** Captures store `source_url`, `captured_at`, exact selected quote, and full page text SHA-256 snapshot in `0-raw/note-snapshots/` so promoting a clipped quote to an approved atom preserves cryptographic byte-offset anchoring.
- **DLP Pre-Screen:** Server-side secret scanner quarantines accidental credentials/cookies automatically.

### Deliverables
- `extensions/browser-clipper/` (Manifest V3 Chrome/Edge/Firefox package)
- One-click pairing token flow in Desktop & Dashboard (`second-brain clipper pair`)
- Automated extension unit + loopback integration tests.

## Milestone 3 — Multi-Vault Workspaces & Access Profiles — COMPLETE

**Goal:** Let owners maintain isolated vaults (e.g., `Personal`, `Work`, `Client-A`) with separate tokens, policies, and encryption keys while supporting fast workspace switching and opt-in cross-vault read-only search.

### Architecture & Invariants
- **Named Vault Registry:** `SecondBrain/security/vaults.json` (`0600`/NTFS DACL) tracks `{vault_id, label, path, default_host_policy}` while keeping `vault-path.txt` as the live active pointer for zero-breakage CLI/MCP/Dashboard/VS Code parity.
- **Strict Isolation Default:** Each vault retains its own `writer.lock`, `decision-record.jsonl`, `vault-ledger.jsonl`, and optional per-vault bearer token; cross-vault recall requires explicit owner opt-in per query and never crosses project/client boundaries implicitly.

### Deliverables
- `second-brain vault list|create|switch|remove`
- Desktop & VS Code quick-switcher dropdown with live API/MCP synchronization
- Isolation penetration tests ensuring vault A credentials/queries never read vault B.

## Milestone 4 — Production Distribution & Trusted Signing

**Goal:** Make installation effortless and warning-free on Windows, macOS, and Linux.

### Deliverables
- **CI/Release Pipeline (`.github/workflows/release.yml` — implemented in `v0.2.0`):** Tag-triggered multi-OS release workflow building Windows `.exe`/`.msi`, macOS universal `.dmg`/`.zip`, Linux `.AppImage`/`.deb`, Python `.whl`, VS Code `.vsix`, and unified `SHA256SUMS.txt`.
- **Trusted Code Signing Secrets (Owner Provisioned):**
  - Windows: CA-issued EV/OV `.pfx` (`WINDOWS_PFX_BASE64`, `WINDOWS_PFX_PASSWORD`) or Azure Trusted Signing so SmartScreen warnings disappear.
  - macOS: Apple Developer ID Application cert + App-Specific notarization (`MAC_CSC_LINK`, `MAC_CSC_KEY_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`).
- **Package Managers & Registries:**
  - PyPI Trusted Publishing (`pip install second-brain` / `uv tool install second-brain`)
  - VS Code Marketplace + Open VSX (`VSCE_PAT`, `OVSX_PAT`)
  - Winget (`winget install SecondBrain.SecondBrain`) and Homebrew Cask (`brew install --cask second-brain`) manifests pointing at versioned GitHub Release checksums.
